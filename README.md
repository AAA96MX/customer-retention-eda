# Análisis de Factores de Retención de Clientes

## 🎯 Objetivo y Metodología
- **Problema:** Analizar indicadores clave de comportamiento de los usuarios y modalidades de contratos para mapear tendencias de consumo y factores de permanencia.
- **Metodología:** Aplicación de Análisis Exploratorio de Datos (EDA) intensivo en Python para identificar patrones de consumo y segmentación.

## 📊 Resultados Clave
- **Hallazgos:** Elaboración de bases analíticas orientadas a respaldar al área de marketing en el diseño de estrategias de retención basadas en datos.

## 🛠️ Tecnologías y Librerías
- **Lenguaje:** Python
- **Librerías y técnicas:** Pandas, Análisis Exploratorio de Datos (EDA), Matplotlib, Seaborn
